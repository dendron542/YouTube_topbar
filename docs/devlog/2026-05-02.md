## スクロール位置ブックマークボタン

- コメント欄などで現在のスクロール位置を記録し、動画上部へジャンプするボタンを追加する。
- 同じボタンの再押下で記録したスクロール位置へ戻る。
- 既存のボタン割り当て設定から選択できるアクションとして実装する。
- 編集前の `pytest` はテスト未配置のため `collected 0 items`。今回の機能用に最小の pytest を追加して Red/Green を確認する。
- `uv run pytest -q`、`uv run ruff format --check .`、`uv run ruff check .`、`uv run pyright` は通過。
