# YouTube Top Controls

YouTubeの動画視聴中にコメント欄にスクロールしても、サイトの上部に再生や音量、巻き戻し、先送りなどのコマンドを常に表示し続けるChrome拡張機能です。

## 機能

- **固定コントロールバー**: ページ上部に常に表示される動画コントロール
- **基本操作**: 再生/一時停止、10秒戻し/送り、音量調整
- **プログレスバー**: 動画の進行状況表示と任意の位置へのシーク
- **時間表示**: 現在時刻と総再生時間の表示
- **レスポンシブデザイン**: 画面サイズに応じた最適化表示
- **YouTubeデザイン統合**: YouTubeの公式デザインに合わせたスタイリング

## インストール方法

### 開発者モードでのインストール

1. **Chrome拡張機能ページを開く**
   - Chromeブラウザで `chrome://extensions/` にアクセス

2. **開発者モードを有効にする**
   - 右上の「開発者モード」トグルをオンにする

3. **拡張機能を読み込む**
   - 「パッケージ化されていない拡張機能を読み込む」をクリック
   - このプロジェクトのフォルダを選択

### ファイル構成

```
YouTube_tops/
├── manifest.json           # 拡張機能の設定ファイル
├── content/
│   ├── youtube-controls.js # メインロジック
│   └── youtube-controls.css # スタイル定義
├── icons/                  # アイコンファイル用ディレクトリ
│   ├── icon16.png          # 16x16ピクセル

│   └── icon128.png         # 128x128ピクセル
└── README.md              # このファイル
```

## 使用方法

1. **拡張機能のインストール後**
   - YouTubeの動画ページ（`youtube.com/watch?v=...`）にアクセス

2. **コントロールバーの表示**
   - ページ上部に黒い半透明のコントロールバーが表示されます
   - コメント欄にスクロールしてもコントロールバーは固定表示されます

3. **操作方法**
   - **再生/一時停止**: 左端の再生ボタンをクリック
   - **10秒戻し/送り**: 再生ボタン横の矢印ボタンをクリック
   - **音量調整**: 音量アイコンクリックでミュート、スライダーで音量調整
   - **動画シーク**: 中央のプログレスバーをクリック
   - **設定/フルスクリーン**: 右端のボタンで元のYouTube機能にアクセス

## 技術仕様

- **対応ブラウザ**: Chrome（Manifest V3）
- **対象サイト**: YouTube動画ページ（youtube.com/watch）
- **パフォーマンス**: イベントスロットリング、エラーハンドリング実装
- **レスポンシブ**: モバイル・タブレット対応

## トラブルシューティング

### コントロールバーが表示されない場合

1. **拡張機能の有効化確認**
   - `chrome://extensions/` で拡張機能が有効になっているか確認

2. **ページのリロード**
   - YouTubeページをリロード（F5またはCtrl+R）

3. **ブラウザコンソール確認**
   - F12でデベロッパーツールを開き、コンソールエラーを確認

### 動作しない機能がある場合

1. **YouTube側の仕様変更**
   - YouTubeのHTML構造変更により一部機能が動作しない可能性

2. **他の拡張機能との競合**
   - 他のYouTube関連拡張機能を一時的に無効化して確認

### バージョン更新手順

1. SemVer（機能追加は minor、不具合修正は patch）に従って
   `manifest.json` の `version` を更新する
2. `CHANGELOG.md` の先頭に同じバージョン、日付、変更内容を追記する
3. `uv run pytest tests/test_version_consistency.py -q` で整合を確認する

バージョン番号の正本は `manifest.json` です。
